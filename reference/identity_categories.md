# Categories offered for the identity of a negative clip

The fixed categories that
[`run_app()`](https://provetelab.org/sheepdog/reference/run_app.md)
suggests, besides the classes of the manifest, for what a negative or
uncertain clip is.

## Usage

``` r
identity_categories()
```

## Value

A character vector.
